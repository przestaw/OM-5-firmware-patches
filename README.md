# OM-5 Firmware Research Notes

Independent technical commentary on the OM SYSTEM OM-5 Mark I: lens
communication, image stabilization, and experimental firmware modifications.

**Start with the [research overview](docs/index.md).**

[Sources and references](docs/sources-and-references.md) ·
[Research notice (EU)](docs/disclaimer.md)

This is a documentation publication, not a patch distribution. It contains
Markdown commentary only — no firmware, tools, patch payloads, replacement
byte sequences, cryptographic keys, build scripts, or installation steps.

## What this is

The chapters under `docs/` are written for other researchers. Each reads on its
own and records what was investigated, which claims are backed by bounded CPU
execution, and where the evidence stops. They are notes toward further work,
not a reproduction package and not a camera-ready release.

Reported results do not establish camera compatibility or installation safety.
Addresses and findings apply to OM-5 Mark I firmware 1.2 and must not be assumed
to transfer to other cameras or firmware versions.
